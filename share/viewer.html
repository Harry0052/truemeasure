TrueMeasure

Place two points on the flat object. The board markers and both points must lie on one plane. The tool withholds a distance when that check, the markers, or the valid region fail.

A: not set. B: not set.

Load the photograph, set two points, attest the plane, then measure.

Units are millimetres. The interval is a sensitivity range from the declared click, marker, and scale bounds. It is not a certified tolerance. Arrow keys nudge the selected point. Tab reaches each control.
