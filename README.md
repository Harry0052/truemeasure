# TrueMeasure

TrueMeasure estimates one distance on a flat object from a photograph that includes a printed reference board in the same plane. It reports millimetres, a sensitivity interval, and the calibration evidence, or it withholds the number when the board, the markers, the valid region, or the operator's coplanarity check cannot support it.

This is a shop documentation aid. It is not a certified metrology instrument.

## Supported platform

Ubuntu 24.04 with:

- g++ 13, which provides C++20
- CMake 3.28 and Ninja
- OpenCV 4.6.x with the contrib ArUco module (`libopencv-dev` and `libopencv-contrib-dev`)
- nlohmann/json 3.11.3 (`nlohmann-json3-dev`)
- clang-format 18, used by the format check
- Python 3, used only by the viewer smoke test and the fixture generator

Other OpenCV versions are outside this release. The CMake build stops when it finds anything other than 4.6.x.

## Install and test

```bash
sudo apt-get update
sudo apt-get install -y g++ cmake ninja-build clang-format \
  libopencv-dev libopencv-contrib-dev nlohmann-json3-dev
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_CXX_COMPILER=g++
cmake --build build
ctest --test-dir build --output-on-failure
```

`ctest` runs the fixture suite and a loopback check of the local viewer. Nothing is downloaded at test time.

## Demo

From the repository root, after the build above:

```bash
./build/truemeasure measure \
  --request fixtures/requests/oblique_60mm.json \
  --json-out out/oblique_60mm.json \
  --annotate out/oblique_60mm.png
```

Stdout is the JSON result. The human summary goes to stderr. On OpenCV 4.6.0 the checked-in oblique fixture produces:

- status `measured`
- `distance_mm` 60.0
- sensitivity interval 59.2 mm to 60.8 mm
- label `60.0 mm [59.2, 60.8] mm`
- units `millimetre`

The report file is `out/oblique_60mm.json`. The annotated photograph is `out/oblique_60mm.png`. The construction length of that segment is 60.0 mm; see `fixtures/oracle/reference.md`. The published distance is rounded to 0.1 mm and must stay within 1.0 mm of 60.0. The interval must contain 60.0.

A view with markers only along the top edge withholds the dimension and exits 2:

```bash
./build/truemeasure measure --request fixtures/requests/top_row_60mm.json
```

Exit codes are 0 for a measurement, 2 when a dimension is withheld, 3 for rejected input, and 1 for usage or an internal failure. `truemeasure --help` prints the commands.

## Placing points

The headless command reads the two pixel endpoints from the request. To choose them on the sample image, start the local viewer and open the URL it prints. It listens on 127.0.0.1 only.

```bash
./build/truemeasure view --request fixtures/requests/oblique_60mm.json --port 8765
```

Click the photograph or use the arrow keys to nudge the selected point. The page does not report a distance until the coplanarity box is checked, and it still withholds a result when the markers or the valid region fail. The viewer calls the same measurement core as the command line.

## What the measurement depends on

The operator must attest that both points and the reference board lie on one plane. The sensitivity interval moves the endpoints by the declared click tolerance, scales the marker corners by the declared corner tolerance, and expands the distance by the declared scale tolerance. It is conditional on that attestation and on the distortion model in the request. It is not a statistical confidence interval and not a certified tolerance.

The valid region is the convex hull of the marker corners used to fit the plane. Points outside that hull produce no distance. Missing, blurred, cropped, or nearly collinear markers produce no distance. A distorted photograph whose request claims there is no distortion is withheld when the marker residuals exceed the calibration bound.

## Fixtures

All photographs are generated by `tools/generate_fixtures.py` with OpenCV `DICT_4X4_50`. No photograph is fetched at runtime, and the repository does not contain bench photos or personal data. Checksums, the generator revision token `20261123`, and the OpenCV license for the marker renderer are in `fixtures/manifest.json`. Regenerating the fixtures requires the same OpenCV 4.6 package and is a maintainer step, not part of the demo.

## Real photographs

A bench workflow is not part of this release. A future owned photograph can use the same request schema once its redistribution terms are recorded. Do not add pictures of people or of objects you do not have rights to publish.

## Layout

- `src/` and `include/truemeasure/` hold image limits, marker detection, geometry, the sensitivity interval, annotation, the command line, and the loopback viewer.
- `fixtures/` holds the versioned board, requests, images, manifest, and oracle.
- `docs/contracts.md` is the input and output contract.
- `docs/validation.md` records the acceptance run.
- `docs/overlap.md` records why this is a separate tool.
